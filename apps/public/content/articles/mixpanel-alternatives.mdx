Mixpanel is a good product analytics tool, and its free plan now covers 1 million events a month. The reasons people look for a Mixpanel alternative start after that: the Growth plan costs $259 a month at 2 million events and $1,176 at 10 million on monthly billing, session replay and feature flags are capped or sold as add-ons, the tracking script sets cookies, and there is no way to run it on your own servers.

This list compares seven alternatives on the things that decide the choice: what you pay at 1 million and 10 million events, whether you can self-host, whether the script needs a cookie banner, and what each tool does that Mixpanel does not. Six more tools get a short mention at the end.

If you only track website traffic (pageviews, referrers, countries) and never custom events, you do not need a Mixpanel alternative at all. Read the [best web analytics tools](/articles/best-web-analytics-tools) instead. If the requirement is to run the tool on your own servers, [self-hosted product analytics](/articles/self-hosted-product-analytics) covers only those options.

## What to check before you switch

Every tool on this list tracks custom events and builds funnels. The differences are in the details below, and they matter more than the feature lists.

Pricing model. Mixpanel, OpenPanel, PostHog and Amplitude charge by events. Pendo charges by monthly active users, Heap by sessions. Event pricing is easy to predict from your current Mixpanel volume. MAU and session pricing can be cheaper for apps with few users who do a lot, and more expensive for consumer apps.

Cookies and consent. Mixpanel's SDK stores a cookie, so in the EU you need a consent banner before it loads, and every visitor who declines is invisible. OpenPanel and Plausible run without cookies. PostHog uses localStorage plus a first-party cookie unless you change its persistence setting.

Self-hosting. If you need the data on your own servers, the list shrinks to OpenPanel, PostHog and Matomo. PostHog's self-hosted version is a hobby deployment the company does not support in production. OpenPanel and Matomo are supported.

Session replay. Mixpanel includes 10,000 replays a month on the free plan and 20,000 on Growth. OpenPanel includes replay with no cap (30-day retention). PostHog meters replay separately after 5,000 recordings a month. Heap and Pendo have replay on paid tiers.

What you will not use. PostHog bundles feature flags, experiments, surveys and error tracking. Pendo bundles in-app guides. If you only need events, funnels, retention and profiles, you pay for scope you do not use, in money or in complexity.

Data export. Check that you can get raw events out through an API or a database dump before you commit. OpenPanel, PostHog and Matomo all give you the raw data; the cloud-only tools vary.

## 1. OpenPanel

<Figure
  src="/content/tools/openpanel-realtime.png"
  caption="OpenPanel combines web and product analytics in a single platform"
/>

Best for: teams that use Mixpanel for events, funnels, retention and profiles, want web analytics in the same dashboard, and would rather not pay per event at Mixpanel's rates.

[OpenPanel](/) was built as a Mixpanel alternative. You get event tracking, funnels, retention, cohorts and user profiles, and the same dashboard shows pageviews, referrers and countries, so one tool replaces Mixpanel plus a web analytics tool. The web script is about 3 KB gzipped and sets no cookies, which means no consent banner for the analytics itself.

It is open source under AGPL-3.0. You can run it on one server with Docker Compose (ClickHouse, Postgres and Redis, installed by a setup script), or use the cloud version hosted in the EU. The self-hosted version is the full product; releases reach it a month or two after Cloud.

### Pricing

OpenPanel Cloud has no free plan. There is a 30-day trial, then you pick an event volume:

| Events per month | Monthly | Mixpanel Growth, monthly billing |
|------------------|---------|-----------------------------------|
| 5,000 | $2.50 | Free |
| 100,000 | $20 | Free |
| 1,000,000 | $90 | Free |
| 2,500,000 | $180 | about $300 |
| 10,000,000 | $350 | $1,176 |

Yearly billing is ten months for twelve. Every plan has unlimited websites, team members, dashboards and tracked profiles, and session replay is included. Self-hosting is free with no event limit.

Under 1 million events Mixpanel is free and OpenPanel is not, so the saving only starts above that line. At 10 million events the difference is $826 a month.

### Key features

- Funnels with steps from any event, a conversion window and breakdown by any property
- Retention tables and curves, saved cohorts
- User profiles with the full event timeline and session history
- Session replay linked to the user's events, inputs masked by default
- Real-time web analytics: pageviews, referrers, UTM, devices, countries
- SDKs for the web, React, Next.js, Vue, React Native, Swift, Kotlin, Python and more, plus an [MCP server](/features/mcp) so you can ask questions from Claude or Cursor

### Pros

- Cheapest option on this list above 1 million events
- Web and product analytics in one place
- Cookie-free by default, data hosted in the EU
- Open source, and self-hosting is supported, not a hobby build

### Cons

- No free cloud plan; the free option is to self-host
- No feature flags, experiments with statistics, surveys or heatmaps
- Younger project with a smaller community than Mixpanel, PostHog or Matomo
- Self-hosting still means you run the servers and the backups

## 2. PostHog

<Figure
  src="/content/tools/posthog.png"
  caption="PostHog offers product analytics plus session replay, feature flags, and more"
/>

Best for: engineering teams that want analytics, feature flags, experiments, surveys and error tracking from one vendor, and products that fit inside the free 1 million events.

PostHog started as open-source product analytics and grew into a developer platform. The analytics part covers everything Mixpanel does: events, funnels, paths, retention, stickiness, plus SQL access to your events through HogQL. Around it sit session replay, feature flags, A/B experiments with significance testing, surveys, error tracking and a data warehouse.

The main browser bundle is about 105 KB gzipped, against 3 KB for OpenPanel and under 1 KB for Plausible. It stores state in localStorage and a first-party cookie by default.

### Pricing

Every product is metered on its own. Product analytics is free for the first 1 million events a month, then $0.00005 per event up to 2 million and $0.0000343 per event from 2 to 15 million, which is about $324 at 10 million events. Session replay is free for 5,000 recordings a month and then billed per recording. Feature flags, surveys and error tracking each have their own free allowance and meter.

Self-hosting is possible but PostHog calls it a hobby deployment and does not support it in production. The stack is ClickHouse, Kafka, ZooKeeper, Redis, Postgres and MinIO.

### Key features

- Events, funnels, paths, retention and stickiness
- Session replay with console logs and network requests
- Feature flags and A/B experiments with statistics
- Surveys, error tracking, heatmaps
- SQL over your events in the dashboard (HogQL)

### Pros

- 1 million free events a month, so small products pay nothing
- The widest feature set on this list
- MIT licensed, active development, large community
- Cheaper than Mixpanel at 10 million events if you only use analytics

### Cons

- Five meters make the bill hard to predict once you use more than one product
- 105 KB script and cookies by default
- Self-hosting is unsupported for production and needs a lot of infrastructure
- More product than a small team needs

<Faqs>
<FaqItem question="How does PostHog's pricing compare to Mixpanel?">
PostHog's free allowance is the same 1 million events as Mixpanel's. Above it PostHog is cheaper for analytics alone: about $324 at 10 million events against Mixpanel's $1,176. Adding session replay, flags and surveys adds separate meters, so compare your full usage, not one line.
</FaqItem>
<FaqItem question="Is PostHog open source?">
The core is MIT licensed. Some enterprise features need a paid licence, and the self-hosted build is a hobby deployment without production support.
</FaqItem>
</Faqs>

## 3. Heap

<Figure
  src="/content/tools/heap.png"
  caption="Heap automatically captures all user interactions without manual tracking"
/>

Best for: product teams that do not want to instrument events up front and will pay for retroactive analysis.

Heap records every click, form submission and pageview automatically. You define events later by pointing at elements in your product, and Heap applies the definition to everything it already captured. That removes the "we should have tracked that" problem that manual tracking has. Heap is now part of Contentsquare.

### Pricing

The free plan covers 10,000 sessions a month with six months of history. Growth, Pro and Premier are priced per session and Heap does not publish the numbers; Growth asks you to install the snippet for an estimate, Pro and Premier go through sales. Heap bills on sessions, not events, so a product with many short visits costs more than one with few long ones.

### Key features

- Autocapture of every interaction, no event code
- Visual event definition after the fact
- Retroactive funnels on data captured before you defined the event
- Session replay
- Enrichment from other data sources

### Pros

- Nothing goes untracked because you forgot to add a call
- Non-technical people can define events
- Includes replay

### Cons

- No public prices above the free plan
- Autocapture stores far more data than you use, and can pick up sensitive input unless you configure exclusions
- Cloud only, proprietary
- Session-based pricing punishes high-traffic, low-engagement products

## 4. Amplitude

<Figure
  src="/content/tools/amplitude.png"
  caption="Amplitude offers advanced product analytics with machine learning features"
/>

Best for: products with high event volume that fit inside the free 2 million events, and larger companies that want data governance and predictive features.

Amplitude is Mixpanel's closest competitor at the enterprise end. It has the same core (events, funnels, retention, cohorts) and adds behavioral cohorting, predictive scores for churn and conversion, and taxonomy tools for keeping event names clean across teams. It is proprietary and cloud only.

### Pricing

The free plan now includes up to 2 million events a month with one year of data access, 10,000 session replays and one active experiment. Plus starts at $0 with the same 2 million free events and scales by event tier up to 70 million events; Amplitude does not publish the per-tier prices. Growth and Enterprise are custom.

### Key features

- Behavioral cohorts and user segmentation
- Predictive metrics for churn and conversion
- Data governance and event taxonomy management
- Web, mobile and server SDKs
- Session replay and experiments on all plans, with limits on Free

### Pros

- Free plan is twice Mixpanel's at 2 million events
- Strong governance for large teams with many event sources
- Mature mobile analytics

### Cons

- No public prices above the free tier
- Cookies by default, so a consent banner in the EU
- Proprietary and cloud only
- More tool than a small team needs

## 5. Pendo

Best for: product managers who want analytics and in-app guides, tooltips and NPS surveys in the same tool, without engineers in the loop.

Pendo pairs behavioral analytics with in-app guidance. You see where users drop off, then ship a walkthrough or announcement to that segment from the same interface, without a code change. Analytics alone is shallower than Mixpanel; the point is the loop from data to in-app action.

### Pricing

Pendo Free covers 500 monthly active users with analytics, guides, Pendo-branded NPS surveys and roadmaps. Base, Core (adds session replay) and Ultimate (adds survey types, orchestration and data sync) are priced per MAU on request. Pendo does not publish paid prices.

### Key features

- Events, funnels, paths and retention
- No-code in-app guides, tooltips and onboarding flows targeted by segment
- NPS, polls and surveys inside the product
- Roadmapping that links feedback and usage data
- Session replay on Core and above

### Pros

- Closes the loop from analytics to in-app action
- Product managers can run it without engineering time
- Feedback and usage data in one place

### Cons

- Paid plans are quoted by sales, with no public price
- Analytics depth is below Mixpanel's
- Heavier SDK than analytics-only tools
- Proprietary and cloud only

## 6. Matomo

Best for: organisations in regulated industries or the public sector that need GDPR compliance on paper and full data ownership, and already run PHP and MySQL.

Matomo (formerly Piwik) is the oldest open-source analytics platform on this list. It is first a web analytics tool and a Google Analytics replacement, with custom events, goals, funnels and cohorts added over the years. Government agencies and universities in the EU use it because the data never leaves their servers and the GDPR tooling (consent, anonymisation, data subject requests) is built in. See the [OpenPanel vs Matomo comparison](/compare/matomo-alternative) for a feature-by-feature view.

### Pricing

Self-hosting is free under GPL-3.0 with unlimited hits. Funnels, heatmaps, session recording and A/B testing are premium plugins sold separately. Matomo Cloud starts at 29 a month excluding tax (Matomo bills in euros or dollars depending on your country) for 50,000 hits and 30 websites, with tiers up to 5 million hits and custom pricing above 10 million.

### Key features

- Web analytics on par with Google Analytics: pages, referrers, campaigns, real time
- Custom events, goals and funnels (funnels are a paid plugin on-premise)
- Heatmaps and session recording as plugins
- Built-in tag manager
- GDPR tooling and Google Analytics import

### Pros

- Fifteen years of development and a large plugin library
- Complete data ownership when self-hosted
- Trusted by EU public bodies for compliance

### Cons

- Product analytics is shallower than Mixpanel's
- Cookies by default; cookieless mode needs configuration
- PHP and MySQL stack to maintain, and the interface looks its age
- The features that make it a Mixpanel replacement are paid plugins

## 7. Google Analytics 4

Best for: teams on a tight budget already inside Google's stack (Ads, Search Console, BigQuery) who need event tracking and basic funnels at any scale.

Most teams already have GA4 before they consider Mixpanel. GA4 is event based, has funnel and path explorations, cohort reports and a free BigQuery export, so it covers more of Mixpanel's ground than Universal Analytics did. It still trails Mixpanel on user-level analysis and real-time debugging, and explorations sample once a query touches more than 10 million events. See our [Google Analytics alternative](/compare/google-analytics-alternative) page for how OpenPanel compares.

### Pricing

GA4 is free. Data retention on the standard property is 2 or 14 months, and explorations are sampled above 10 million events per query. GA4 360 removes those limits and starts around $50,000 a year.

### Key features

- Event model with parameters, like Mixpanel
- Funnel, path and cohort explorations
- Free raw export to BigQuery for SQL
- Predictive metrics for purchase and churn probability
- Deep integration with Google Ads and Search Console

### Pros

- Free at any volume
- Ties analytics to ad spend better than any other tool
- The largest community and the most tutorials

### Cons

- Cookies and a consent banner in the EU, and data processed on Google's servers
- 14 months of retention and sampled explorations on the free property
- User-level analysis is limited compared to Mixpanel
- Not open source; your data is part of Google's advertising business

## Which Mixpanel alternative should you pick?

Choose OpenPanel if you want Mixpanel's core (events, funnels, retention, profiles, replay) plus web analytics, with a cookie-free script and a price that stays flat above 1 million events, and you may want to self-host.

Choose PostHog if you want feature flags, experiments, surveys and SQL from the same vendor, or your product fits inside the free 1 million events and you do not mind the 105 KB script.

Choose Heap if you will not instrument events and want to define them after the fact, and you can live without public pricing.

Choose Amplitude if you have under 2 million events a month and want the free plan, or you are a large company that needs governance and predictive features.

Choose Pendo if the in-app guides and NPS are the point and analytics is secondary.

Choose Matomo if you need an on-premise tool with GDPR tooling that auditors already know, and you have a PHP team.

Choose GA4 if you need free analytics tied to Google Ads and can accept cookies, sampling and 14 months of retention.

## Six more worth a look

[Countly](/compare/countly-alternative) is open-source mobile and web analytics with push notifications and crash reporting built in, priced per MAU from $80 a month, with a self-hosted Lite edition for non-commercial use.

[Kissmetrics](https://www.kissmetrics.io/) ties events to revenue for SaaS and e-commerce. One of the original Mixpanel competitors, now a niche pick for teams that think in customer lifetime value.

[FullStory](/compare/fullstory-alternative) is session replay and heatmaps first, with product analytics on top. Built for UX teams with enterprise budgets; no free analytics plan.

[Statsig](https://www.statsig.com/) is an experimentation platform from ex-Facebook engineers with product analytics added later. Pick it when experiments matter more than reporting.

[Plausible](/compare/plausible-alternative) is cookie-free web analytics with a one-page dashboard, from $9 a month. It does not replace Mixpanel's product analytics, but if pageviews and goals are all you need, it is the simplest tool here.

[Umami](/compare/umami-alternative) is MIT-licensed web analytics you can self-host for free. Same caveat as Plausible: web analytics only.

For a wider list of tools, including Mixpanel itself, see the [best product analytics tools](/articles/best-product-analytics-tools). If PostHog is the tool you are leaving, read the [best PostHog alternatives](/articles/posthog-alternatives).

## Migrating off Mixpanel

Export first. Mixpanel's export API gives you raw events as JSON; most tools on this list can import them, and OpenPanel has a [migration guide](/guides/migrate-from-mixpanel).

Map the SDK calls. Track, identify and set-property calls exist in every tool, usually with the same names. OpenPanel has SDKs for [Next.js](/docs/sdks/nextjs), [React](/docs/sdks/react), [Vue](/docs/sdks/vue), [Python](/docs/sdks/python) and [more](/docs/sdks).

Check the features you use, not the ones you have. List the reports your team opened in the last month and confirm the new tool builds them. The [OpenPanel vs Mixpanel](/compare/mixpanel-alternative) page lists what is missing on each side.

Count the full cost. For self-hosted tools, add the server and the hours; for cloud tools, add the meters you will hit beyond events, such as replays and flags.
