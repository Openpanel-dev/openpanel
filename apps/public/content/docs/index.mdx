## What is OpenPanel?

OpenPanel is open-source web and product analytics. One script gives you the traffic numbers you would get from Plausible or Google Analytics, and the same events power product reports like [funnels](/features/funnels), [retention](/features/retention), user profiles and [session replay](/features/session-replay).

Tracking is cookie-less by default, and the code is AGPL licensed on [GitHub](https://github.com/Openpanel-dev/openpanel).

## Cloud or self-hosted

Both run the same product. OpenPanel Cloud is hosted in the EU and starts with a 30-day free trial. Self-hosting is free and runs with Docker Compose.
